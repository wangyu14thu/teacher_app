# 收益记录本

一张简单的本地理财收益表，纯 HTML / CSS / JavaScript，无需安装依赖。

## 本地使用

在本目录运行：

```bash
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。首次联网打开后可以离线使用，也可安装到手机主屏幕。直接打开 index.html 也可以使用表格，但建议固定使用同一个本地地址，以保证浏览器存储位置一致。

## 每天怎么记

1. 点击「管理产品」，设置产品名称、本金，以及开始记账前的累计收益（期初收益）。新账本为空，不预填产品或收益。
2. 点击「新增记录」，在弹窗选择日期，填写各产品的**最新持仓总金额（含本金和收益）**。点击保存后，累计收益 = 持仓金额 − 本金，其他汇总自动更新；表格不可直接编辑。选择已有日期可修改记录，保存会替换当天记录，留空的产品不保留当天记录。取消不保存。
3. 涨跌 = 本次累计收益减去上次记录，第一笔减去产品期初收益。周收益按周一至周日汇总；跨月周仅计算当前月部分。漏记几天后的差额会全部落在下一次记录日期。
4. 本月收益 = 本月末累计收益减去月初前最近记录；无记录时沿用期初收益。持仓金额 = 本金 + 累计收益。月底前显示的是当前已录入的最近值。
5. 当日仅填部分产品时，累计总收益沿用其他产品最近值，标记 `*`；当日增减仅计算当天已填产品。

本金与期初收益是每个产品的固定设置，不用于记录申购、赎回或分红流水。修改这两个设置会重算整张表。

## 数据与备份

- 「清空全部数据」经确认后清除本浏览器全部产品、收益记录及旧版账本；不会影响其他设备。

- 数据仅在当前浏览器 localStorage 中保存，不上传服务器。手机与电脑不自动同步。
- 用「导出备份」保存完整 JSON 文件，「导入备份」可以恢复全部月份。导入会先校验文件，再确认替换。
- 「导出表格」导出当前月 CSV，可用 Excel 打开。
- 删除产品并保存时，如果含历史记录，会要求确认删除。建议先备份。
- 旧版资产账本存储键 `fangcun-ledger-v1` 保留，不自动把账户余额转换成收益；存在旧数据时，页面底部可以单独导出。新版使用 `fangcun-returns-v2`。
- 清理浏览器数据、更换浏览器、地址端口或设备前，先导出备份。浏览器本地保存不等于已写入电脑中的备份文件。
