# 方寸账本

一个完全本地存储的个人资产管理 PWA：电脑浏览器显示桌面布局，Android 与 iOS 可安装到主屏幕。

在线地址：<https://wangyu14thu.github.io/teacher_app/>

## 本地运行

在本目录启动任意静态文件服务：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。手机与电脑在同一局域网时，也可以访问电脑的局域网地址。首次打开后，浏览器会缓存应用文件以供离线使用。

## 数据说明

- 账户和每日金额保存在当前浏览器的 `localStorage` 中；电脑与手机默认互不关联。
- 如需手动迁移数据，可以在原设备导出备份，在新设备导入备份。
- 应用不向任何服务上传数据。
- 更换浏览器、清理站点数据或更换手机前，请先在“设置”中导出备份。
