# TabBar 图标说明

## 需要准备的图标文件

请在此目录下放置以下 6 个图标文件：

### 1. 首页图标
- `home.png` - 未选中状态（建议灰色 #999999）
- `home-active.png` - 选中状态（蓝色 #4A90E2）

### 2. 消息图标
- `message.png` - 未选中状态（建议灰色 #999999）
- `message-active.png` - 选中状态（蓝色 #4A90E2）

### 3. 我的图标
- `profile.png` - 未选中状态（建议灰色 #999999）
- `profile-active.png` - 选中状态（蓝色 #4A90E2）

## 图标规范

- **尺寸**：81px × 81px（推荐）
- **格式**：PNG
- **大小**：每个文件必须小于 40kb
- **建议**：使用简单的矢量图标，避免复杂图片

## 图标来源推荐

1. **iconfont（阿里图标库）**：https://www.iconfont.cn/
2. **TinyPNG（图片压缩）**：https://tinypng.com/
3. **IconPark（字节跳动图标库）**：https://iconpark.oceanengine.com/

## 快速制作步骤

1. 访问 iconfont.cn
2. 搜索 "首页"、"消息"、"用户" 等关键词
3. 选择喜欢的图标，下载 PNG 格式（81px）
4. 准备两个版本：
   - 灰色版本作为未选中状态
   - 蓝色版本（#4A90E2）作为选中状态
5. 确保每个文件小于 40kb
6. 将文件重命名并放入此目录

## 临时方案

如果暂时没有合适的图标，可以：
1. 使用在线工具生成简单的纯色图标
2. 使用微信开发者工具自带的默认图标
3. 从其他小程序项目复制符合规范的图标
