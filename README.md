# 收益记录本

一张简单的本地理财收益表，纯 HTML / CSS / JavaScript，无需安装依赖。

## 本地使用

在本目录运行：

```bash
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。首次联网打开后可以离线使用，也可安装到手机主屏幕。直接打开 index.html 也可以使用表格，但建议固定使用同一个本地地址，以保证浏览器存储位置一致。

## 每天怎么记

1. 点击「管理产品」，设置产品名称、期初本金，以及开始记账前的累计收益（期初收益）。新账本为空，不预填产品或收益。
2. 点击「新增记录」，在弹窗选择日期，填写各产品截至当天的**累计收益总额**：盈利填正数，亏损为负数，最多两位小数。保存后更新对应日期及各项汇总；也可双击表格中的「收益」单元格（包括空白记录），弹窗自动定位日期和产品，点击「确认更新」才保存；取消、关闭或按 Esc 不保存。键盘聚焦单元格后可按 Enter 打开。选择已有日期可修改记录，保存会替换当天记录，留空的产品不保留当天记录。
3. 表格「收益」表示截至所选日期的累计总收益，直接按累计值填写。「涨幅」= 当天累计收益 − 上一日累计收益（元）；任一天未记录时显示 `—`，跨月按实际前一日比较。修改历史日期不会更改其他日期已经填写的累计值，但会自动重算对应涨幅。周收益按周一至周日汇总；跨月周仅计算当前月部分。
4. 本月收益 = 本月末累计收益减去月初前最近记录；无记录时沿用期初收益。持仓金额 = 当日本金 + 累计收益。月底前显示的是当前已录入的最近值。
5. 当日仅填部分产品时，累计总收益沿用其他产品最近值，标记 `*`；当日增减按当日已记录产品的涨幅汇总。

期初本金是每个产品开始记账时的本金。之后点击「本金变动」，按日期登记追加（正数）或取出（负数）；变动从当天起计入本金，月末本金、持仓金额及后续日期的本金会同步更新，不会改写收益记录。取出金额不能超过当时本金。点击日期下方的本金变动标记，可修改或删除当天记录。期初收益仍是开始记账前已有的累计收益；修改期初本金或期初收益会重算相关汇总。

## 数据与备份

- 「清空全部数据」经确认后清除本浏览器全部产品、收益记录及旧版账本；不会影响其他设备。

- 数据仅在当前浏览器 localStorage 中保存，不上传服务器。手机与电脑不自动同步。
- 用「导出备份」保存完整 JSON 文件，「导入备份」可以恢复全部月份。导入会先校验文件，再确认替换。
- 「导出表格」导出当前月 CSV，可用 Excel 打开。
- 删除产品并保存时，如果含历史记录，会要求确认删除。建议先备份。
- 旧版资产账本存储键 `fangcun-ledger-v1` 保留，不自动把账户余额转换成收益；存在旧数据时，页面底部可以单独导出。继续使用存储键 `fangcun-returns-v2`，数据格式为 version 6（每日累计收益、本金变动、逐笔持仓及工资规划）。读取 version 2 备份时原累计收益保持不变；读取 version 3 备份时，会按日期将每日收益累加成累计收益；version 4 备份会自动补上空的本金变动表。
- 清理浏览器数据、更换浏览器、地址端口或设备前，先导出备份。浏览器本地保存不等于已写入电脑中的备份文件。

## 产品趋势

点击「产品趋势」切换到曲线页。每个产品独立展示累计收益（元），可选择当前月份或全部记录。横轴按实际日期间隔绘制，仅连接真实记录，漏记不补零；只有一条记录时显示单点。正收益红色、负收益绿色，负收益不等同于负债。展开「查看曲线数据」可查看各日期金额。

访问 `?reset=1` 会弹出清空确认，确认后删除当前浏览器新旧账本数据；取消不会删除。普通访问不会自动清空。

## 发财芽与 DeepSeek 对话

右下角小精灵可打开聊天窗口。消息只保留在当前页面内存，清除对话或刷新即清除；账本数据不会自动发送。只有主动输入的聊天内容和最近对话发送给 DeepSeek。

使用 Node.js 22+ 在项目根目录运行 `node server/ledger-server.cjs`，打开 `http://127.0.0.1:4174`。在服务器环境中配置 `DEEPSEEK_API_KEY`（不要写入前端文件、提交到 Git 或发送到聊天中），可通过 `PORT` 修改端口。默认模型为 `deepseek-chat`。

GitHub Pages 只能展示静态页面，不能运行此接口。线上 AI 对话需部署 Node 服务并通过同源反向代理访问 `/api/chat`。该服务默认只监听本机；对外开放前应由反向代理提供登录访问控制及限流，避免接口被他人消耗额度。离线时账本可用，AI 对话需要联网。

### 网页配置 API Key

打开发财芽 →「设置」，输入 DeepSeek API Key，可测试连接并应用到本次页面。网页 Key 优先于服务器的 `DEEPSEEK_API_KEY`，仅在页面内存中保留，刷新即清除；清除后回退服务器默认配置。请求经本站 `/api/chat` 转发到 DeepSeek，不写入服务器配置、不进入备份。线上必须使用 HTTPS；测试连接会产生少量 API 用量。纯 GitHub Pages 仍需部署同源后端接口，填写 Key 本身不能代替后端部署。

## 资产管理：每个月都有钱回来

新增第三个页签「资产管理」，支持同一产品多笔买入批次，记录买入日、本金、到期日、可选的预计到期本息，以及持有中 / 已到账状态。活期或未知到期日留空；未知本息留空，不自动估算收益。编辑或删除批次不会修改收益明细和本金。

- **到期日历**：从北京时间当前月起看 12 / 18 / 24 个月；柱状图按本金汇总，点击月份查看产品明细。已到账、未来买入和逾期未确认的批次不计入未来到期；逾期、活期单独提醒。集中度 = 窗口内最大单月到期本金 / 窗口内到期本金总额。
- **工资预算**：可投入金额 = max(0, 本次工资 + 已可用资金 − 本月支出 − 需补留备用金)。已可用资金可包含实际收到的到期资金，但不能重复填写工资或未到账资金。
- **空档与期限试算**：设置每月到期本金目标，选择空缺月份和计划买入日，反推按自然日计算的期限范围；输入候选产品实际到期日及金额，检查是否匹配月份、是否超预算，显示投放前后本金与剩余缺口。试算不自动买入或保存为持仓。
- **每月操作**：核实到账和持仓 → 留足支出与备用金 → 补最近空档 → 对照风险等级、费用、起购门槛、赎回与到账规则选产品 → 买入后登记 → 到账后滚动规划。期限建议是本地规则计算，不是 AI 产品推荐。

现有收益仍按累计收益记录，未自动与持仓买卖联动。补录已有持仓不重复增加本金；真实新买入 / 赎回请另在「本金变动」登记。部分赎回可将原批次拆为剩余持有与已到账两笔。到期日不等于到账日，预计本息不作为确定现金或月目标覆盖依据。

备份格式升级为 version 6，包含 `lots` 和 `planning`；兼容读取 version 2–5，旧备份自动补空持仓和零预算，不自动生成样例资产。导出、导入、清空和删除产品均覆盖新增数据。截图里的资产未自动导入，避免与真实账本重复。

验证（Node.js 22+）：`node asset-ledger/tests/daily-returns.test.cjs`（在仓库根目录执行）。
