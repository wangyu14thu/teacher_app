# 跨学科项目教学小程序

一个面向教师的跨学科项目式教学辅助小程序，包含教师端和审核员端两个系统。

## 📱 功能模块

### 教师端

#### 🏠 首页
- 专题讲座
- 项目案例库（按年级分类）
- 我的项目（设计与实施）

#### 💬 消息与助手
- **系统消息**：接收审核结果、学校通知等
- **AI助手**：智能对话助手（规划中）

#### 👤 我的
- 个人信息管理
- 我的积分
- 我的项目（设计/购买）
- 创建学校团队
- 我的学校
- 管理后台（仅管理员）

### 审核员端

#### 📋 任务看板
- 今日待审核数
- 本周已完成数
- 待审核项目列表
- 待审核学校列表

#### ✅ 审核功能
- 项目审核（通过/驳回）
- 学校申请审核
- 自动生成邀请码
- 发送系统消息

---

## 🗄️ 数据库设计

### 核心集合

1. **`schools_pending`** - 学校申请（待审核）
2. **`schools`** - 正式学校记录
3. **`projects_pending`** - 项目申请（待审核）
4. **`reviewers`** - 审核员账号
5. **`system_messages`** - 系统消息
6. **`application_logs`** - 申请日志

---

## ☁️ 云函数

### 1. `reviewer` 云函数
- 审核员登录认证
- 获取待审核任务
- 审核学校申请
- 审核项目提交
- 获取用户消息

### 2. `school-application` 云函数
- 提交学校申请
- 提交项目审核
- 获取我的学校
- 智能分配审核员

---

## 🚀 快速开始

### 1. 数据库初始化

在**云开发控制台 → 数据库**中创建以下集合：

```
schools_pending
schools
projects_pending
reviewers
system_messages
application_logs
```

### 2. 创建审核员账号

在 `reviewers` 集合中添加记录：

```json
{
  "account": "reviewer",
  "password": "123456",
  "name": "审核员张三",
  "role": "reviewer",
  "status": "active",
  "gradeLevel": ["1-2年级", "3-4年级"],
  "department": "内容审核部",
  "createdAt": "2026-01-31T00:00:00.000Z"
}
```

### 3. 部署云函数

右键点击云函数文件夹 → **"上传并部署：云端安装依赖"**

- `cloudfunctions/reviewer`
- `cloudfunctions/school-application`

### 4. 测试流程

#### 教师端测试
1. 填写个人信息
2. 创建学校团队 → 提交申请
3. 设计项目 → 申请评估/发布项目
4. 查看"消息与助手"接收审核结果

#### 审核员端测试
1. 访问审核员登录页（隐藏入口）
2. 登录账号：`reviewer` / `123456`
3. 查看待审核任务
4. 审核学校/项目
5. 系统自动生成邀请码并发送消息
