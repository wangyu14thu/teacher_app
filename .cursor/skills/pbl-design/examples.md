# 跨学科项目化学习案例库

## 案例1：校园垃圾分类大作战

**年级：** 三年级  
**学科：** 科学 + 数学 + 美术 + 语文  
**时长：** 4周  

### 项目依据
**真实世界情境：**
学校推行垃圾分类政策，但学生对垃圾分类的认知不足，分类效果不理想。

**课标对接：**
- 科学：认识材料、了解环境保护
- 数学：数据收集与统计、图表制作
- 美术：海报设计、标识设计
- 语文：调查报告写作、倡议书写作

**学生学情：**
三年级学生对环保有初步认识，具备基本的调查和表达能力，喜欢动手操作。

### 驱动性问题
**核心问题：** 我们如何让校园垃圾分类变得更容易、更有趣？

**子问题：**
1. 现在学校垃圾分类存在什么问题？
2. 垃圾应该如何正确分类？
3. 怎样设计让同学们一看就懂的分类标识？
4. 如何让更多同学参与到垃圾分类中来？

### 学习活动设计

**第一阶段：问题发现（1周）**
- **活动1：** 校园垃圾桶观察记录
- **活动2：** 采访保洁员和同学
- **活动3：** 统计一周垃圾分类错误率
- **成果：** 问题调查报告

**第二阶段：知识探究（1周）**
- **活动1：** 学习垃圾分类知识（科学课）
- **活动2：** 参观垃圾处理站
- **活动3：** 分类实验游戏
- **成果：** 垃圾分类知识手册

**第三阶段：方案设计（1周）**
- **活动1：** 设计垃圾桶分类标识（美术）
- **活动2：** 制作分类指南海报
- **活动3：** 编写分类口诀和儿歌
- **成果：** 完整的宣传方案

**第四阶段：实施推广（1周）**
- **活动1：** 在班级试点推广
- **活动2：** 制作视频和广播稿
- **活动3：** 全校宣传活动
- **成果：** 实施效果报告

### 评估方案

**形成性评估：**
- 观察记录表（每周）
- 小组讨论记录
- 学习日志

**总结性评估：**
- 调查报告（语文能力）
- 数据统计图表（数学能力）
- 海报和标识设计（美术能力）
- 科学知识测试（科学知识）
- 小组展示答辩（综合能力）

**评分权重：**
- 科学知识：30%
- 数据分析：20%
- 创意设计：20%
- 语言表达：15%
- 团队合作：15%

### 所需资源
- 不同类型的垃圾样品（清洁的）
- 统计表格和图表工具
- 美术材料（纸张、颜料、剪刀等）
- 平板电脑或相机（记录拍摄）
- 参观垃圾处理站的安排

## 案例2：我们的班级图书馆

**年级：** 四年级  
**学科：** 数学 + 语文 + 信息技术  
**时长：** 6周  

### 项目依据
**真实世界情境：**
班级有很多图书，但管理混乱，经常找不到书，借阅也不规范。

**课标对接：**
- 数学：分类统计、数据整理、编码规则
- 语文：书籍分类、读书报告、推荐理由写作
- 信息技术：Excel使用、二维码生成、简单数据库

**学生学情：**
四年级学生已有一定阅读经验，具备基本的数学统计能力和信息技术操作能力。

### 驱动性问题
**核心问题：** 如何建立一个高效、有趣的班级图书管理系统？

**子问题：**
1. 我们有多少本书？应该怎么分类？
2. 怎样为每本书设计独特的编码？
3. 如何记录借阅情况？
4. 怎样让同学们更愿意借书？

### 学习活动设计

**第一阶段：图书盘点（1周）**
- 清点图书数量
- 学习图书分类法
- 建立图书清单
- **数学融合：** 统计、分类、制表

**第二阶段：编码系统设计（2周）**
- 学习图书编码规则
- 设计班级图书编码系统
- 为每本书编号和贴标签
- 生成二维码书签
- **数学融合：** 数字编码、逻辑规则
- **信息技术融合：** Excel数据处理、二维码生成

**第三阶段：借阅系统开发（2周）**
- 设计借阅登记表
- 创建Excel借阅管理表
- 制定借阅规则
- **数学融合：** 统计分析、时间计算
- **语文融合：** 规则说明书写

**第四阶段：阅读推广（1周）**
- 撰写图书推荐卡
- 设计阅读积分制度
- 举办新书推介会
- **语文融合：** 推荐语写作、演讲展示

### 评估方案

**过程评估：**
| 阶段 | 评估内容 | 评估方式 |
|-----|---------|---------|
| 盘点 | 分类准确性 | 教师检查 + 同伴互评 |
| 编码 | 编码规则合理性 | 小组展示 + 教师评价 |
| 系统 | 操作可行性 | 实际测试 + 用户反馈 |
| 推广 | 推荐质量 | 投票 + 借阅数据 |

**最终评估：**
- 图书管理系统完整性（40%）
- 数学编码与统计（25%）
- 信息技术应用（20%）
- 语言表达与写作（15%）

### 所需资源
- Excel或WPS软件
- 标签纸、打印机
- 二维码生成器（在线工具或应用）
- 图书分类参考资料
- 可选：简单的图书管理小程序模板

## 案例3：神奇的桥

**年级：** 五年级  
**学科：** 科学 + 数学 + 美术 + 信息技术  
**时长：** 8周  

### 项目依据
**真实世界情境：**
学校附近正在建设新的跨河大桥，引发学生对桥梁结构的好奇。

**课标对接：**
- 科学：力与运动、结构与稳定性
- 数学：测量、比例、几何图形
- 美术：结构设计、模型制作
- 信息技术：3D建模、数据可视化

**学生学情：**
五年级学生具备一定的科学探究能力和动手能力，对工程技术有兴趣。

### 驱动性问题
**核心问题：** 什么样的桥梁结构最坚固又最美观？

**子问题：**
1. 世界上有哪些著名的桥？它们的结构有什么特点？
2. 什么因素影响桥梁的承重能力？
3. 如何设计一座既美观又实用的桥？
4. 怎样用有限的材料建造最坚固的桥？

### 学习活动设计

**第一阶段：桥梁探秘（2周）**
- 调研不同类型的桥梁
- 参观在建大桥（或视频学习）
- 采访工程师
- **科学融合：** 桥梁结构原理
- **数学融合：** 测量与比例
- **成果：** 桥梁研究报告

**第二阶段：结构实验（2周）**
- 学习三角形稳定性原理
- 测试不同结构的承重力
- 记录实验数据
- 分析数据规律
- **科学融合：** 力学实验
- **数学融合：** 数据收集与统计分析
- **成果：** 实验报告和数据图表

**第三阶段：桥梁设计（2周）**
- 设计桥梁草图
- 绘制工程图纸
- 创建3D模型（可选）
- 计算材料用量
- **数学融合：** 几何绘图、比例计算
- **美术融合：** 美学设计
- **信息技术融合：** 3D建模
- **成果：** 设计方案书

**第四阶段：制作与测试（2周）**
- 按设计制作桥梁模型
- 进行承重测试
- 记录测试数据
- 优化改进设计
- **科学融合：** 实践验证
- **数学融合：** 承重比计算
- **成果：** 桥梁模型和测试报告

### 评估方案

**分阶段评估：**
| 阶段 | 核心能力 | 评估方式 | 权重 |
|-----|---------|---------|------|
| 探秘 | 调研能力 | 研究报告 | 15% |
| 实验 | 科学探究 | 实验记录和数据分析 | 25% |
| 设计 | 创新设计 | 设计方案书 | 30% |
| 制作 | 实践能力 | 模型质量和承重测试 | 30% |

**综合评估维度：**
- **科学理解**（30%）：力学原理应用、实验操作
- **数学应用**（25%）：测量、计算、数据分析
- **创意设计**（20%）：创新性、美观性
- **工程实践**（15%）：制作质量、功能实现
- **团队协作**（10%）：分工、沟通、协作

**最终展示：**
- 桥梁模型展览
- 设计理念演讲
- 承重挑战赛
- 最佳设计奖、最强承重奖、最美桥梁奖

### 所需资源
- **结构材料**：竹签、吸管、雪糕棒、胶水、绳子
- **测试设备**：砝码、测力计、电子秤
- **设计工具**：绘图纸、尺子、圆规、计算器
- **技术资源**：3D建模软件（SketchUp等，可选）
- **参考资料**：桥梁图册、工程视频
- **场地**：实验室或美工教室

### 差异化策略
- **基础组**：使用简单材料（吸管），设计基础桥型（梁桥）
- **进阶组**：使用复合材料，设计拱桥或桁架桥
- **挑战组**：限制材料用量，追求最大承重比，尝试悬索桥设计

## 案例4：传统节日文化节

**年级：** 六年级  
**学科：** 语文 + 数学 + 美术 + 信息技术 + 社会  
**时长：** 6周  

### 项目依据
**真实世界情境：**
传统节日文化在年轻一代中逐渐淡化，学校计划举办传统文化节，需要学生深度参与策划和组织。

**课标对接：**
- 语文：古诗词鉴赏、传统文化理解、说明文写作
- 数学：预算规划、比例计算、统计分析
- 美术：传统艺术创作、展台设计
- 信息技术：多媒体制作、电子海报设计
- 社会：历史文化、民俗研究

**学生学情：**
六年级学生具备较强的独立研究能力和组织能力，对传统文化有一定认知基础。

### 驱动性问题
**核心问题：** 如何策划一场让同学们深度体验传统文化的节日活动？

**子问题：**
1. 传统节日有哪些独特的文化内涵？
2. 怎样让传统习俗变得有趣、吸引人？
3. 如何合理规划活动预算和资源？
4. 怎样通过现代技术传播传统文化？

### 学习活动设计

**第一阶段：文化探究（2周）**

**小组分工研究不同节日：**
- 春节组、清明组、端午组、中秋组、重阳组

**研究内容：**
- 节日起源与历史演变
- 传统习俗和禁忌
- 诗词歌赋与传说故事
- 传统食品与制作工艺
- 现代传承现状

**研究方法：**
- 查阅资料（图书馆、网络）
- 采访长辈
- 实地考察（民俗馆、文化街区）

**学科融合：**
- 语文：诗词赏析、文化解读、采访记录
- 社会：历史脉络、地域差异

**成果：** 节日文化研究报告（5000字）+ PPT展示

**第二阶段：活动策划（2周）**

**策划任务：**
1. 设计节日体验活动方案
2. 制定活动流程和时间表
3. 规划场地布局
4. 预算资源和物料
5. 设计宣传方案

**小组工作坊：**
- 创意工作坊：设计互动游戏和体验活动
- 预算工作坊：估算成本、寻找资源
- 宣传工作坊：设计海报、视频、公众号文章

**学科融合：**
- 数学：预算计算、空间规划、时间分配
- 语文：活动方案撰写、宣传文案
- 信息技术：电子海报、宣传视频制作

**成果：** 完整的活动策划书

**第三阶段：创作准备（1周）**

**创作任务：**
- 制作传统手工艺品（剪纸、灯笼、香囊等）
- 排练传统表演（诗朗诵、情景剧、民乐）
- 准备传统美食展示
- 布置文化展台

**学科融合：**
- 美术：传统工艺品制作、展台设计
- 语文：剧本创作、朗诵表演
- 数学：材料用量计算、展台空间设计

**成果：** 各类展品和表演节目

**第四阶段：活动实施与总结（1周）**

**实施：**
- 搭建展台
- 举办文化节活动
- 组织互动体验
- 记录活动过程

**总结：**
- 收集参与者反馈
- 统计活动数据
- 撰写活动总结报告
- 制作纪念册或视频

**学科融合：**
- 数学：统计参与人数、满意度分析
- 语文：总结报告、纪念册文字
- 信息技术：活动视频剪辑、数据可视化

**成果：** 活动总结报告 + 纪念视频

### 评估方案

**过程评估（50%）：**
| 评估项 | 方式 | 权重 |
|-------|------|------|
| 文化研究 | 研究报告质量、展示效果 | 15% |
| 策划能力 | 策划书完整性、可行性 | 15% |
| 创作实践 | 作品质量、创新性 | 10% |
| 团队协作 | 分工合理性、沟通效率 | 10% |

**成果评估（50%）：**
| 评估项 | 方式 | 权重 |
|-------|------|------|
| 活动效果 | 参与度、满意度、影响力 | 20% |
| 文化理解 | 深度、准确性、创新诠释 | 15% |
| 综合能力 | 知识应用、问题解决 | 15% |

**多元评估主体：**
- 自我评估（20%）
- 同伴互评（20%）
- 教师评价（40%）
- 参与者评价（20%）

### 所需资源

**物质资源：**
- 手工材料：彩纸、布料、颜料、竹子等
- 展台材料：桌椅、展板、装饰品
- 多媒体设备：投影仪、音响、电脑
- 传统服装（租借或制作）

**人力资源：**
- 民俗专家讲座
- 手工艺人指导
- 家长志愿者支持

**学习资源：**
- 图书：《中国传统节日》《民俗文化大全》
- 纪录片：《我在中国》《舌尖上的中国》节日篇
- 网站：国家非物质文化遗产网

**场地资源：**
- 图书馆（研究）
- 美术教室（创作）
- 操场或礼堂（活动）

**预算估算：**
- 材料费：约500-800元
- 宣传费：约200元
- 其他：约300元
- 总计：约1000-1300元

### 差异化策略

**支持策略：**
- 为研究能力较弱学生提供资料包和研究指南
- 为动手能力弱的学生提供模板和详细步骤
- 为表达困难的学生提供发言提纲和演练机会

**挑战任务：**
- 优秀学生担任小组长和活动总协调
- 设计跨节日对比研究
- 创作传统文化现代演绎作品（如说唱版古诗、动画短片）
- 进行活动效果的深度数据分析

**灵活分组：**
- 研究组（擅长阅读和分析）
- 策划组（擅长组织和协调）
- 创作组（擅长动手和艺术）
- 技术组（擅长信息技术）

学生可根据兴趣和特长选择主要参与组，同时也参与其他组的部分工作，确保全面发展。

## 案例5：水资源保护行动

**年级：** 五年级  
**学科：** 科学 + 数学 + 语文 + 社会  
**时长：** 5周  

### 项目依据
**真实世界情境：**
某地区遭遇干旱，水资源紧缺引发社会关注，学校发起节水行动。

**课标对接：**
- 科学：水的循环、水资源分布、水污染与净化
- 数学：数据收集、统计分析、估算
- 语文：调查报告、倡议书、新闻稿
- 社会：资源保护、可持续发展

### 驱动性问题
**核心问题：** 我们能为水资源保护做些什么？

**子问题：**
1. 我们日常用水量有多大？哪里最浪费？
2. 水资源短缺会带来什么影响？
3. 有哪些有效的节水方法？
4. 如何让更多人参与到节水行动中？

### 学习活动设计

**第一阶段：水资源调查（1周）**
- 记录家庭一周用水情况
- 学校用水情况调查
- 计算人均用水量
- **数学融合：** 测量、统计、比较

**第二阶段：科学探究（1周）**
- 水的净化实验
- 探究不同水污染物的危害
- 学习水循环知识
- **科学融合：** 实验探究

**第三阶段：方案设计（2周）**
- 设计家庭节水计划
- 设计学校节水方案
- 计算节水效益
- 撰写倡议书
- **数学融合：** 方案测算
- **语文融合：** 文案写作

**第四阶段：宣传实施（1周）**
- 制作宣传材料
- 社区宣讲
- 实施监督
- **语文融合：** 演讲、写作
- **社会融合：** 公民责任

### 所需资源
- 水表读数记录表
- 水质检测试剂
